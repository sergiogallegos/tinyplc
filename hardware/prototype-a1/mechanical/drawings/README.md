# A1 drawing and assembly package

- [Construction bundle](tinyplc-a1-drawings.pdf): four A4 sheets, at actual size.
- [Visual assembly booklet](assembly-guide.pdf): sequential Blender illustrations.
- [Technical procedure](technical-assembly-reference.pdf): detailed assembly and power-up changes.
- [Applied label master](05-applied-labels.pdf): physical-size top/side lettering.
- [Lens mask](lens-mask-front.svg): 64 × 32 mm front-view artwork; mirror for reverse printing.

Print dimensioned drawings at 100%, without fit-to-page, and measure the 100 mm
scale bar. Assembly illustrations are not scale drawings. Front-view lens-mask
coordinates differ from the numerical case XY drawing view; apply by the
labelled PWR/RUN positions and confirm with the LEDs before bonding.

Native geometry is in [FreeCAD](../tinyplc-a1.FCStd), with mm print STLs one level
above. Case fit, screw retention, cable clearances and optical performance are
not physically tested. The PCB remains unrouted. Read the
[engineering decisions](../../../../docs/hardware/prototype-a1-design.md).
