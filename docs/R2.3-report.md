# R2.3: layout, build and initial hardware evidence

2026-09-30. Added the [experimental memory layout](memory-layout.md), static
FreeRTOS configuration, project-owned startup, privileged periodic-task scaffold
and RAM instruction-fetch probe. The build script checks the pinned kernel
archive and GCC version, retains upstream license, and makes a generated copy
with privileged-only general peripheral access. No upstream source is vendored.

Arm GNU 13.3.Rel1 was downloaded from Arm and extracted in temporary storage,
without a global install. SHA-256 matches Arm's published checksum; URL and
checksum are recorded in the target lock. The target now compiles and links
with GCC 13.3.1. Linker measurements: privileged flash 14,544 B, veneers 440 B,
privileged RAM 4,448 B, separate 2 KiB task stack and 4 KiB MSP reservation.
See the layout guide for slot reservations and stack-estimation limitations.

Passed: target build with warnings as errors (one documented assembly-wrapper
unused-parameter exception), no unresolved symbols, ELF section/vector/RAM-entry
checks, and rejection of an intentionally overflowing input section. The linked
RAM probe is four bytes at 0x20010000; this establishes placement, not execution.

After the user authorized board tests, ST-LINK identified STM32F446 (ID
0x10006421) with 512 KiB flash. The scaffold was programmed and verified.
Observed RAM probe result: 42; assertion latch: 0; task iterations: 159;
FreeRTOS ticks: 1587; free stack: 488 of 512 words. These establish initial
RAM instruction fetch and scheduler/stack observations, not worst-case bounds.

R2.3 acceptance is complete for this scaffold. Subsequent ST-native execution
and corrected input-region permissions are documented in [R2.4](R2.4-report.md).
Full unprivileged protection and deadline fault tests remain R2.6 work.
